# Release Manifest

This flat release contains 15 project files in the repository root: one final manuscript PDF, two notebooks, one standalone Python audit script, one saved AtCoder JSON report, two CoREB CSV result tables, three Markdown documentation files, two environment manifests, a SHA-256 checksum list, and a `.gitignore` file.

There are no nested project folders and no relative Markdown hyperlinks. File names in the README and run guide match the files in the repository root.

Raw AtCoder, CoREB, and XLCoST datasets are not included. The main research notebook is archival and stateful; do not use “Run All”. The CoREB data loader blocks are pinned to one immutable revision documented in the README and run guide. The optional legacy XLCoST cells depend on an unverified Google Drive share link and are not required for the final AtCoder/CoREB analyses.

The saved result files are supplied outputs from prior Colab runs. Packaging checks do not constitute a fresh experiment rerun or independent replication.
